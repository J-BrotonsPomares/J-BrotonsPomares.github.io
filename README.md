# J-BrotonsPomares.github.io

Portfolio profesional bilingüe de José Brotons Pomares, construido con Hugo.

## Publicación
1. Sube **todo el contenido interior** de esta carpeta a la raíz del repositorio `J-BrotonsPomares.github.io`.
2. Comprueba que existe `.github/workflows/hugo.yaml`.
3. En `Settings > Pages`, selecciona `GitHub Actions` como Source.
4. En la pestaña `Actions`, abre `Deploy Hugo site to Pages` y comprueba que termine en verde.
5. Visita `https://J-BrotonsPomares.github.io/`.

No subas la carpeta `public`; GitHub Actions la genera automáticamente.
